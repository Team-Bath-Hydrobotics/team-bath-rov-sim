# Team Bath Rov Sim
Investigating the use of HoloOcean E2E simulation for the rover.
HoloOcean [GitHub](https://github.com/wellscrosby/MRGHoloOcean) and [docs](https://byu-holoocean.github.io/holoocean-docs/develop/index.html)

## Manual controls

Keyboard controls are W/A/S/D for forward/backward and strafe, left/right
arrows for yaw, up/down arrows for vertical movement, Q/E for roll, and R/F
for pitch. An Xbox controller may also be used: the left stick maps to
W/A/S/D movement, the right stick controls yaw and pitch, D-pad left/right
controls roll, and A/B control ascend/descend. Controllers connected while
the simulator is running are detected automatically.
